## 一、杨立昆是谁？凭什么这么说？

先认识一下这位爷。

**杨立昆（Yann LeCun）**，图灵奖得主——计算机界的诺贝尔奖。和辛顿（Hinton）、本希奥（Bengio）并称**"AI教父三人组"**，三人2018年一起领的奖。他发明了卷积神经网络（CNN），你手机里的人脸识别、自动驾驶汽车看路、医院里的CT影像分析，都跟他有直接关系。

他曾经是Meta（就是Facebook那个Meta）的首席AI科学家，一手打造了FAIR（基础人工智能研究院），那是全球最顶尖的AI实验室之一。

然后，在2025年底，他**跑了**。

不是被开除，是主动走的。理由？**Meta不是干这事的地方。** 他成立了自己的实验室——AMI Labs，总部设在巴黎，一分钱硅谷风投都不拿，专心搞他的"世界模型"。

这操作，像极了一个顶级厨师离开了五星级酒店，去街边开了家只做一道菜的小店。不是因为酒店不好，是因为酒店的菜单不允许他做那道菜。

## 二、核心观点：LLM到底怎么了？

### 1. LLM不是不行，是走错了方向

杨立昆的原话很克制：**"大语言模型本身没有错，它们是很有用的产品。"**

但他紧接着话锋一转：**"它们不是通往人类水平智能的路。"**

什么意思？就是说，ChatGPT、Claude、Gemini这些大模型，确实是好产品，能写文章、能编程、能翻译、能当你的24小时客服。但如果你想让AI变成一个真正"理解世界"的智能体？**靠这些模型，永远做不到。**

为什么？因为LLM本质上是个**文字接龙机器**。它通过预测下一个token来"思考"，但它：

- **不知道推一下水瓶会发生什么**（物理世界理解）
- **不知道说了这句话对方会怎么反应**（因果推理）
- **不会提前规划三步之后的事**（长远规划）

它就像一个读过全世界所有书但从没出过门的人。你说"下雨了"，它能接"记得带伞"；但你让它真的在雨天开车，它连雨刮器在哪都不知道。

### 2. 现实世界 vs 语言：根本不是一回事

这里有个关键的认知差异，很多人没意识到：

|                | 语言              | 现实世界           |
| -------------- | ----------------- | ------------------ |
| **维度**       | 一维序列          | 高维连续空间       |
| **性质**       | 离散、符号化      | 连续、充满噪点     |
| **结构**       | 有语法、有逻辑    | 杂乱无章、充满意外 |
| **适合的架构** | 自回归模型（GPT） | 需要全新的范式     |

语言是人类为了交流而发明的**压缩工具**。它把复杂的世界压缩成了一个个词。LLM学会了这套压缩工具的规律，但它并没有真正"理解"被压缩的那个世界。

打个比方：你可以通过读一万本菜谱成为美食评论家，但你永远变不成厨师——因为你从来没碰过锅。

## 三、世界模型：杨立昆的"真命天子"

### 什么是世界模型？

简单说，就是让AI拥有一个**脑子里的沙盘**。

你在现实生活中做任何事之前，都会在脑子里先"模拟"一下：

- "如果我把杯子推到桌子边缘，它会掉下去" → 所以你不推
- "如果我现在变道，后面的车可能会撞我" → 所以你先看后视镜
- "如果我对老板说这句话，他可能会发火" → 所以你换个说法

这种"预判后果"的能力，就是**世界模型**。

杨立昆认为，**没有世界模型的系统，根本算不上真正的智能体。** 一个无法预判自身行为后果的AI，就像一个闭着眼睛开车的人——偶尔能走直线，但迟早出事。

### 智能行为的三大支柱

杨立昆总结了真正智能行为的三个不可或缺的特征：

**1. 预判后果**

> 能够想象"如果我做X，会发生Y"

**2. 规划能力**

> 通过搜索和优化，找到达成目标的最佳动作序列。注意：不是像LLM那样一个token一个token地"猜"，而是**全局搜索**，像下棋一样想好后面好几步。

**3. 抽象预测**

> 不需要在像素级别预测世界的变化，而是在**抽象表征层面**进行。

### 杨立昆的经典比喻：推水瓶

> "我面前有一个拧开盖子的水瓶。推底部，它会滑动；推顶部，它会翻倒。我们无法精确预测瓶子会怎么倒、水会怎么洒。我们绝不可能在像素级别预测这些细节。但我们的大脑确实在预测——只不过是在**抽象层面**进行的。"

这就是关键：人类的心智模型不需要预测每一个像素，它只需要预测**重要的抽象特征**。JEPA架构就是基于这个洞察设计的。

## 四、JEPA：杨立昆押注的"下一个大东西"

### 一句话解释

**JEPA（Joint Embedding Predictive Architecture，联合嵌入预测架构）** = 在抽象表征空间里做预测，而不是在像素级别做预测。

### 为什么生成式方法不行？

杨立昆讲了一个让他顿悟的观察：

> **"所有在学习图像和视频表征方面取得巨大成功的架构，无一例外都是非生成式的；而所有生成式的架构，基本上都以失败告终。"**

他举了三个"翻车"的例子：

| 方法                    | 问题                                         |
| ----------------------- | -------------------------------------------- |
| **VAE（变分自编码器）** | 在大模型上只能学到恒等映射——等于白学         |
| **MAE（掩码自编码器）** | Meta砸了大量算力搞这个项目，结果令人大失所望 |
| **扩散模型**            | 能生成漂亮图片，但没学到真正有用的世界表征   |

而与此同时，**联合嵌入架构**（JEPA的前身）却在巴黎和纽约默默取得了突破性进展。

### JEPA怎么工作？

想象你有一张照片，你把它"破坏"了一下（比如遮住一部分）。然后：

1. 把**原图**输入编码器A，得到表征A
2. 把**破坏后的图**输入编码器B，得到表征B
3. 训练一个预测器，用表征B去**预测**表征A

关键区别在于：**预测发生在抽象表征空间，不是像素空间。** 这意味着模型学到的是"这个世界是怎么运作的"，而不是"这个像素应该是什么颜色"。

### 系统一 vs 系统二

杨立昆借用了心理学的经典概念来解释：

- **系统一**：直觉反应，快、自动、不需要动脑。比如你看到一张图就知道是猫。
- **系统二**：深思熟虑，慢、费力、需要规划。比如你在下棋时想后面五步怎么走。

**当前的LLM本质上只是系统一**——它能快速生成看似合理的回答，但它不会真正"思考"。JEPA的目标是让AI具备**系统二**的能力——能够想象、预判、规划。

### VLA：已被判死刑

顺便说一句，杨立昆对VLA（视觉-语言-动作模型，就是用LLM来控制机器人那套）给出了直接判决：

> **"VLA没有什么前途，它真的行不通。"**

原因：不够可靠，数据需求太大，而且本质上还是在用自回归的方式一个动作一个动作地"猜"，缺乏全局规划能力。

## 五、数据效率：人类 vs AI，差距有多大？

杨立昆提到了一个让人扎心的对比：

> **人类学开车只需要大约20小时。**

20小时。而训练一个自动驾驶AI需要多少数据？数百万英里的路测数据，加上海量的模拟数据。

这说明什么？说明当前AI的学习方式**极其低效**。人类之所以学得快，是因为我们有强大的先验知识——我们从小就在理解物理世界、因果关系、物体运动规律。我们不需要从零开始学习"杯子被推了会倒"这种常识。

杨立昆认为，真正的AI突破应该是**数据效率的突破**——不是通过堆更多数据和算力来暴力破解，而是让AI学会像人类一样**从少量经验中快速学习**。

> "我们不应该通过合成数据无止境地堆砌计算量。"

## 六、硅谷的"羊群效应"：一场全行业的集体迷失

这部分是杨立昆批评最尖锐的地方。

他的观察是：硅谷正在经历一场**严重的从众效应**。

- OpenAI搞LLM火了 → 所有人都去搞LLM
- Google跟上 → Meta跟上 → 亚马逊跟上 → 创业公司也跟上
- 探索性研究被边缘化 → 创新空间萎缩
- 开源精神退潮 → 闭源垄断趋势抬头

结果就是：**所有人都在做同一件事，整个行业变得极其同质化。**

这就像一群人都在同一个金矿里挖，越挖越深，越挖越卷，但没人愿意抬头看看旁边是不是有更好的矿脉。

杨立昆的大胆预测：

> **"整个AI行业将在2027年初彻底醒悟，迎接这场范式的转变。"**

## 七、AI主权与Tapestry：不被任何国家"文化洗脑"

这部分挺有意思的，涉及到地缘政治。

杨立昆观察到一个趋势：**大多数国家不希望被美国或中国的AI模型"文化洗脑"。**

想想也是：如果全世界都用同一个AI模型，而这个模型的训练数据、价值观、世界观都来自某一个国家，那其他国家的文化和价值观就会被逐渐侵蚀。

这就是为什么**AI主权**成了各国的共识——每个国家都想要自己的AI能力。

杨立昆参与的**Tapestry项目**就是为了解决这个问题：

- 通过**分布式参数向量贡献**和**联邦学习**机制
- 构建一个**全球共享的开源基础模型**
- 各国可以在这个基础上定制符合自己文化和价值观的AI

简单说：一个底层共享的开源模型 + 各国的本地化定制 = 既全球化又多元化的AI生态。

## 八、AI安全：杨立昆 vs 辛顿 & 本希奥

三位图灵奖得主，曾经并肩作战的战友，现在在AI安全问题上**分道扬镳了**。

| 维度        | 杨立昆                      | 辛顿/本希奥           |
| ----------- | --------------------------- | --------------------- |
| 对LLM的态度 | 怀疑，认为走不通            | 相对认可其潜力        |
| AI末日论    | 被严重夸大                  | 真的很担忧            |
| 安全路径    | 目标驱动的底层设计          | 需要外部监管          |
| 核心分歧    | LLM太弱了，根本威胁不到人类 | LLM太强了，可能会失控 |

杨立昆的逻辑其实很简单：

> "你们说AI要统治世界了？拜托，连个水瓶怎么倒都预测不了的系统，凭什么统治世界？"

他认为，"AI末日论"被严重夸大了，而且这种恐慌情绪正在被某些利益集团利用，推动过度监管，反而会阻碍创新。

**真正的风险不是AI变"邪恶"，而是：**

- 技术应用不当导致的社会不平等
- 缺乏明确目标函数约束下的系统行为失控
- 权力过度集中在少数科技公司手中

他主张的安全路径是：**在系统底层通过"目标驱动"设计来实现安全，而不是靠外部的监管强制。**

## 九、离开Meta的内幕：不是被赶走，是待不下去了

这是访谈中最劲爆的部分之一。

### 误解一：杨立昆深度参与了Llama开发？

**错。** 杨立昆明确表示：**他对Llama模型没有任何技术层面的参与。**

外界一直以为他是Llama背后的核心人物，但实际上他和团队一直在做JEPA和世界模型，跟Llama完全两条线。

### 误解二：他是被Meta赶走的？

**也错。** 扎克伯格、CTO博斯沃思对他的项目其实很感兴趣，也很支持。问题出在**公司层面**：

- Meta意识到自己在LLM竞赛中落后了
- 于是全力转向LLM，追赶OpenAI和Google
- 探索性研究（包括JEPA和世界模型）被边缘化
- 虽然高层支持，但公司资源和注意力已经完全倾斜到LLM上

### 根本原因：Meta不是做这事的地方

随着JEPA研究取得进展，杨立昆意识到：

1. 必须从纯研究转向**产品落地**
2. 世界模型的主要应用（机器人、制造业）**不在Meta的核心业务范围内**
3. 需要一个**独立、专注、不受短期业绩压力**的环境

于是，AMI Labs诞生了。

### 顺便一提：Mistral AI也是这么来的

访谈中还提到，FAIR的其他团队成员也因为类似的原因出走，创立了Mistral AI。大公司的基础研究实验室，正在成为AI创业的**黄埔军校**。

| 维度         | AMI Labs                   | 典型硅谷AI公司 |
| ------------ | -------------------------- | -------------- |
| **总部**     | 巴黎                       | 旧金山/硅谷    |

**为什么选巴黎？** 因为巴黎和纽约是联合嵌入架构研究的发源地，而且欧洲的研究文化更注重长期基础研究，不像硅谷那样要求"三个月出demo，六个月见营收"。

**为什么不拿硅谷风投？** 因为硅谷的钱是有条件的——快速增长、快速变现、快速退出。而杨立昆要做的事，需要的是**耐心**和**自由**。

## 十一、技术干货对比表

### 生成式架构 vs JEPA

| 维度     | 生成式架构         | JEPA               |
| -------- | ------------------ | ------------------ |
| 预测目标 | 像素级别重构       | 抽象表征空间       |
| 计算效率 | 低（生成大量像素） | 高（只在抽象层面） |
| 表征质量 | 容易坍缩           | 有意义的抽象表征   |
| 物理理解 | 弱                 | 强                 |
| 数据需求 | 极高               | 相对较低           |
| 代表方法 | VAE、MAE、扩散模型 | JEPA、联合嵌入架构 |

### LLM vs 世界模型

| 维度     | LLM                   | 世界模型               |
| -------- | --------------------- | ---------------------- |
| 推理方式 | 自回归（逐token预测） | 搜索与优化（全局规划） |
| 预判能力 | 无                    | 核心能力               |
| 物理理解 | 弱                    | 强                     |
| 系统类型 | 系统一（直觉）        | 系统二（深思熟虑）     |
| 适合场景 | 文本、代码、符号推理  | 物理世界交互、机器人   |

## 最后的话

**"LLM是好产品，但不是好智能。真正的智能需要理解物理世界，需要能预判后果、能规划未来。硅谷正在集体走错路，但我已经找到了正确的方向，你们2027年再来看。"**
